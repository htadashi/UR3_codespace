# Simulador do UR3 no codespace com ROS2

1. Inicialize um novo codespace no branch `ROS2`
2. Rode o comando `install_ros2.sh` para instalar o ROS2 e demais dependências
3. Use o comando `run_docker.sh` para inicializar o servidor do simulador do UR
4. Em outro terminal, use o comando `test_control.sh` para testar a comunicação entre o ROS e o simulador do UR
